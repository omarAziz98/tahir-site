# tahir5dailyprayers.com

Website for **Tahir**, a prayer companion app for iPhone: home page, privacy policy (`/privacy/`) and support (`/support/`).

Plain static HTML, served by GitHub Pages. The colours and the sky that changes through the day (`assets/sky.js`) follow the app's Sky Clock design.

Fonts are Sora and DM Sans, used under the SIL Open Font License (see `assets/fonts/`).
